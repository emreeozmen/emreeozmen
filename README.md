### 🚀 Featured project

**Financial Risk &amp; Portfolio Analysis Platform**

A full-stack finance app that pulls real price data across BIST and global markets and lets
users build a weighted portfolio and analyze its risk/return profile.

- 📈 Real-time data from Yahoo Finance, live price/news feed over WebSocket
- 📉 Risk metrics: Sharpe ratio, volatility, drawdown, correlation matrix
- ⚖️ Portfolio optimization: Max Sharpe / Min Variance / Risk Parity (`scipy`)
- 🕯️ Candlestick charts, technical indicators (SMA / RSI / MACD), fundamentals
- 🧾 FIFO-based realized P&amp;L tracking and tax report
- 🔗 Shareable portfolio links, PDF/CSV export, multi-currency support
- 🔐 Secure auth with 2FA, session management, activity log
- 🌗 Light/dark theme, PWA support, fully localized UI

**Stack:** FastAPI · PostgreSQL · Redis · WebSocket · scipy · yfinance · React · TypeScript · Vite · Chart.js · Render · Vercel · Sentry

🔗 **Live:** https://portfolio-analyzer-smoky.vercel.app
🔗 **Code:** https://github.com/emreeozmen/portfolio-analyzer
